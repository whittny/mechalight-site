V2A 연구개발

소리가 없는 영상을 보고, 화면 속 사건에 맞는 효과음과 배경음을 프레임 단위로 만들어 내는 Video-to-Audio 모델을 개발하고 있습니다.

진행 중: 학습 데이터 정제와 모델 설계

01 영상 속 움직임02 속도별 타이어 마찰음03 방향과 거리의 입체 음향

작동 방식

  1. 영상 이해

    비디오 인코더가 프레임마다 장면, 동작, 물체를 읽어냅니다.

  2. 타이밍 맞춤과 생성

    프레임 단위 정렬 모듈이 사건 시점을 잡고, Flow Matching 기반 생성 모델이 소리를 만듭니다. 텍스트로 소리의 느낌을 조절할 수도 있습니다.

  3. 48kHz 오디오 출력

    편집에 바로 쓸 수 있는 고음질 효과음과 배경음을 내보냅니다.

개발 로드맵

  1. 데이터 정제

    공개 영상-오디오 데이터에서 화면과 소리가 맞지 않는 샘플을 걸러내고 특징을 추출합니다.

  2. 대규모 학습

    영상, 텍스트, 오디오를 함께 학습하는 멀티노드 분산학습을 진행합니다.

  3. 평가와 최적화

    공개 벤치마크에서 기존 공개 모델과 비교하고 생성 속도를 높입니다.

  4. 시험 공개

    크리에이터와 제작사가 써 볼 수 있는 API 형태의 시험 버전을 준비합니다.
